# VisionWeb — Design direction

## Brand character
Independent, confident, modern and welcoming. The public storefront should feel like a curated 2026 digital studio catalogue rather than a generic template marketplace. The admin area should be calm, clear and practical.

## Visual system
- Dark charcoal and warm off-white foundations.
- Acid-lime highlight with occasional orange accent.
- Syne display typography for expressive headlines.
- DM Sans for readable interface copy.
- DM Mono for labels, categories and technical metadata.
- Large editorial photography, asymmetrical hero composition, restrained motion and generous spacing.

## Public storefront experience
- Strong hero introducing the collection.
- Clear category filters and search.
- Project cards show category, image, project title, USD price, inclusions and a WhatsApp enquiry action.
- Project detail dialog includes longer description, features and demo link.
- Repeated manual-payment notice: no online checkout; payment is arranged in WhatsApp.
- Contact details remain easy to find; floating WhatsApp shortcut stays visible.

## Admin dashboard experience
- Separate `/admin.html` private route/page.
- Quiet login surface and clear dashboard status.
- Summary counts for total, published and draft projects.
- Project editor with obvious required fields, image upload, editable USD price and publish toggle.
- Responsive project list with edit and delete actions.
- No customer payment UI and no unnecessary customer data collection.

## Responsive and accessibility notes
- Mobile-first reflow for dashboard lists and form fields.
- Visible focus states, semantic labels, accessible dialogs, descriptive button text and status messages.
- Respect reduced-motion preferences.
